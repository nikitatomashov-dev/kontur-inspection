# Контур — обследование зданий

Веб-приложение для карт и ведомостей дефектов, прочностей и обмерных эскизов.

## Открытие с телефона

В настройках репозитория: Settings → Pages → Deploy from a branch → main → / (root) → Save. Откройте опубликованный HTTPS-адрес в Safari или Chrome. Можно добавить приложение на главный экран.

## Данные

Объекты, чертежи и фотографии сохраняются локально в браузере. Автоматической синхронизации устройств пока нет. Для переноса используйте «Скачать проект» на исходном устройстве и «Открыть проект» на другом. Локальный адрес и опубликованный сайт имеют отдельные хранилища.

После первого полного открытия приложение кэширует ресурсы для офлайн-работы. Регулярно скачивайте резервные копии проектов; очистка данных браузера может удалить локальные объекты.

В репозитории находятся только программа и её библиотеки. Mozilla PDF.js и лицензии включены в vendor/pdfjs.
